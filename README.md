# J-CAG
J-CAG is a Sublime Text plugin. A Python script acts as a bridge between the Sublime Text environment and the GPT server, supporting real-time communication and providing a seamless experience.

**Comment Analysis**
The project consists of two parts. The first part focuses on analyzing JavaDoc comments. The predefined JavaDoc is created by the developer based on the function’s purpose and how it works. The function and its corresponding comment are sent to the GPT server as a request. The result is returned as a simple yes/no answer for ease of use by developers. A ‘‘Yes’’ means the function aligns with the comment, while a ‘‘No’’ is followed by a brief explanation to help the developer understand the issue. From there, it is up to the developer to decide whether to modify the function or the comment for improvement.

**Comment Generation**
The second part involves comment generation. This tool can be used for the repetitive task of generating JavaDoc comments for simple functions. The newly generated comment will appear above the function definition with a click of a button.
Like the first part, this follows a request/response model. The Java function is sent to the GPT server as a request, and the response is a JavaDoc comment generated by the GPT model to match the function.

To use this plug-in, simply obtain an API key from the OpenAI website. https://platform.openai.com/settings/organization/api-keys 

Then, place the two Python files in the appropriate location within the Sublime Text directory. 

Below is an example showing where I saved these files on my machine.

~/Library/Application Support/Sublime Text/Packages/User/add_gutter_symbol.py

~/Library/Application Support/Sublime Text/Packages/User/gpt_integration_2.py

~/Library/Application Support/Sublime Text/Packages/Default/Default (OSX).sublime-keymap

You can also create a new plug-in and copy the source code into the new Python file. Sublime Text will automatically save the file in the appropriate location.
